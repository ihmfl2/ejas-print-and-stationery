File Requirements

Sebelum mengirimkan dokumen untuk dicetak, pastikan file telah memenuhi persyaratan berikut:

  • File menggunakan format PDF, DOCX, atau JPG.
  • Dokumen dapat dibuka dengan baik.
  • Ukuran dan orientasi kertas sudah sesuai.
  • Periksa kembali isi dokumen sebelum dicetak.
  • Pastikan gambar memiliki kualitas yang cukup jelas.

How to Order

  1. Siapkan file dokumen yang ingin dicetak.
  2. Kirim file kepada pihak toko.
  3. Tentukan jenis layanan dan ukuran kertas.
  4. Konfirmasi jumlah halaman dan pesanan.
  5. Ambil hasil cetakan setelah selesai.
