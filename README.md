# EJAS Print and Stationery

## Tentang EJAS

Selamat datang di website EJAS Print and Stationery!

EJAS merupakan toko alat tulis kantor (ATK) dan fotokopi yang berdiri sejak tahun 1998. Nama EJAS berasal dari empat pendiri inti, yaitu Alexis, Julius, Evelyn, dan Samuel.

Website ini dibuat untuk memperkenalkan toko EJAS kepada masyarakat, memberikan informasi mengenai produk dan layanan, memudahkan pelanggan mendapatkan informasi, serta membantu mempromosikan toko agar dapat menjangkau lebih banyak pelanggan.

EJAS memiliki ciri khas dengan kombinasi warna navy blue, putih, dan soft teal.

### Informasi Toko

- Alamat: Jl. Nurul Huda Aliamin Komplek Bumi Makmur No. A12
- Tahun berdiri: 1998
- Target pelanggan: Mahasiswa, pelajar, guru, dan masyarakat umum.

## Tujuan Website

Website EJAS Print and Stationery dibuat sebagai media informasi dan promosi toko. Melalui website ini, pengunjung dapat mengenal EJAS, melihat produk dan layanan yang tersedia, mengetahui informasi harga, serta menemukan informasi kontak toko.

## Teknologi yang Digunakan

Website EJAS dikembangkan menggunakan:

- HTML: Untuk menyusun struktur dan isi halaman website.
- CSS: Untuk mengatur tampilan, warna, tata letak, dan desain website.

## Panduan Membuka Website

Untuk membuka website EJAS melalui Visual Studio Code, ikuti langkah-langkah berikut:

1. Buka folder proyek EJAS di Visual Studio Code.
2. Pastikan extension Live Server sudah terpasang.
3. Buka file index.html`.
4. Klik kanan pada area editor yang kosong.
5. Pilih Open with Live Server**.
6. Website akan terbuka melalui browser.
